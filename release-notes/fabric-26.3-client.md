### Fabric 26.3 — Client Only

Local FBX player models for Minecraft 26.3, including model previews, rig and animation settings, first-person controls, Default shape keys, and Voice Shape using a local microphone or optional Simple Voice Chat.

This variant displays your own model on your client. It requires no server-side installation and sends no model files, appearance settings, or voice-animation levels. Gameplay rendering follows the client-only single-player/local-network connection policy; model editing remains available outside those connections. FBX entities and model sharing are available in the full Fabric variant.

Install either the full or client-only 26.3 jar in a game instance. Both use the `fbx-player-models` mod ID.
