### Fabric 1.21.1 — Client Only

This client-only Fabric 1.21.1 version is provided for future-proofing [Aksu's Peaceful Gameplay Pack](https://modrinth.com/modpack/aksus-peaceful-gameplay-pack).

It includes local FBX model previews, rig and animation settings, first-person controls, Default shape-key sliders and previews, and Voice Shape bone/shape-key mappings using a local microphone or optional Simple Voice Chat. It shares the full Fabric version's UpAxis-aware FBX importer, binary shape-key recovery, normalization, and deformation code.

It displays only your own model, requires no server-side installation, and does not share model files, appearance settings, or voice-animation levels with other players. FBX entities remain exclusive to the full version. Install the client-only jar on its own; it uses the same Fabric mod ID as the full version.
