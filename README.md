# The Source Code of FBX Player Models

This is an AI-assisted fork of [AllTheSkins by 1TheCrazy](https://github.com/1TheCrazy/AllTheSkins).

Here you can see source code of FBX Player Models.

Use an FBX model as your Minecraft player skin in single-player and LAN games.

This release is experimental and made for playing with friends. Public multiplayer is outside its supported scope. You can see technical notes [here](TECH_NOTES.md).

Download the mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fbx-player-models) platform or from [here](https://github.com/aksulightning/FBXPlayerModels/releases). Modrinth platform is no longer supported, due their changed AI policies.
