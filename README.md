There is a basic template available for now.

[https://raw.githubusercontent.com/aksulightning/FBXPlayerModels/refs/heads/template/FPM_template.fbx](https://raw.githubusercontent.com/aksulightning/FBXPlayerModels/refs/heads/template/FPM_template.fbx)

For the best chance of working, use a simple model exported from Blender.

Good models usually have:

Low detail.
One material.
A texture.
Clear bone names.
A file size under 2 MB.

The rig names like Head, Chest, Right Arm, Left Arm, Right Leg, and Left Leg can help the mod guess the right body parts.


If you’re using Blender, the export settings are mostly the default ones. See the settings below.
